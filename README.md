# 故事神谕 · 模板广场

这里存放大家分享的「自定义模板」（故事神谕 ✨ 校正 → 自定义）。每个模板只是一段文字提示词，
下载后会出现在你自己的模板列表里，像手写的模板一样使用。

## 怎么用
- 在神谕的「自定义」面板点「🌐 广场」浏览、预览、下载。
- 在自己的模板上点「📤 分享」：「提交分享」一键投稿；连不上时点「复制分享文本」发到神谕 Discord 的模板分享频道。

## 规则
- 分享后模板公开，任何人都能下载使用。
- 每份投稿都要经过审核，通过后才会出现在广场里。
- 只收纯文字模板；名字 ≤40 字、正文 ≤8000 字、标签 1–3 个（从 `tags.json` 里选）。

## 目录
- `templates/<编号>/template.txt` — 模板正文
- `templates/<编号>/meta.json` — 名字、作者、说明、标签、测试模型、版本
- `tags.json` — 可选标签
- `dist/library.json` — 自动生成，神谕读的就是它（不要手改）

## 投稿格式（Discord 转贴时照原样贴进新 Issue）
投稿文本里有一段以 `<!-- SO-TEMPLATE v1 -->` 开头的区块，发布脚本只认这一段。
